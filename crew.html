참여 등록한 크루 명단이에요. 미참여 신고 전 꼭 확인해주세요!
불러오는 중...
참여 규칙
①참여 시간 11:00 ~ 22:00 / 완료 시간 22:00 ~ 다음날 10:00
②해시태그 복사 후 피드에 작성 → 앱에서 참여 등록
③완료 시간에 해시태그 2~3회 재검색 후 꼼꼼히 좋아요 → 완료 체크
④밴링크 등록은 11:00 ~ 22:00 (해시태그 미노출 시에만)
⑤주 2회 이상 완료 필수 (월~일 기준)
봉사 규칙
①주 완료 0회 또는 1회 → 봉사 1회 (매주 월요일 10:15 자동 부여)
②완료 체크 미처리 → 봉사 1회 (매일 10:10 자동 부여)
③봉사 처리: 참여 유형 [봉사 참여] 선택 → 참여 + 완료 체크
④봉사 발생 후 3일 이내 미처리 → 계정 자동 잠금
⑤봉사 3회 누적 → 계정 즉시 잠금 (운영진 문의)
⑥허위 밴링크 등록 신고 처리 시 봉사 부여
참여 유형
●일반 참여 — 완료 체크 필수, 주완료 횟수 포함
B봉사 참여 — 봉사 있을 때만 가능, 완료 시 봉사 1회 차감, 주완료 미포함
🏅명예/운영진 — 완료 체크 면제, 좋아요 면제, 주완료 1회 인정
명예회원
①주 7회 완료 달성 시 명예권 자동 부여 (7일 유효)
②명예권 보유 시 [명예/운영진] 유형으로 참여 가능
③명예 참여 시 명예권 1개 차감, 완료 체크 면제
④7일 이내 미사용 시 명예권 자동 만료
주의사항
⚠️입장 첫 주(월~일)는 연습 기간 — 봉사 면제, 참여는 가능
⚠️해태 / 무임승차 / 먹튀 → 연계방 전체 차단 (1,500명+)
⚠️1인 1일 1참여, 참여 등록 + 완료 체크 둘 다 해야 인정
✋ 참여 등록
1인 1회 참여만 가능합니다. 해시태그에 누락된 경우 참여 링크를 등록해주세요.
✅ 완료 체크
해시태그 2~3회 재검색 후 꼼꼼히 좋아요 눌렀나요? 밴 링크도 챙겨주세요!
🔗 밴링크 등록
해시태그에 걸리지 않은(밴) 경우 링크를 등록해주세요.
등록된 밴링크는 다른 크루에게 공유됩니다.
✈️ 휴가 신청
휴가 기간 동안은 봉사가 면제됩니다. 운영진 승인 후 적용됩니다.
